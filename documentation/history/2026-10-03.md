# 2026-10-03: Anthropic API key moved to SecretStorage

## Accomplished

- `anthropicApiKey` (plaintext in data.json) replaced by `anthropicApiKeySecretName` (SecretStorage name, default `note-village-anthropic-api-key`). Settings row uses `SecretComponent` via `setting.addComponent`.
- Key read at use time: `plugin.getAnthropicApiKey()` → `resolveApiKey` (SecretStorage, then legacy fallback migrated on read). `ConversationManager` takes a key getter and rebuilds its client only when the key changes; `setApiKey` removed.
- Cross-device migration (`src/app/services/api-key-secret.ts`, `bootstrapApiKeySecret`): legacy plaintext kept as a read-only per-device bootstrap; every device copies it into its own SecretStorage on load. `legacySecretMigratedAt` records the first migration; legacy removed after 60 days, on rotation (secret differs from legacy, or a different secret picked), on **Clear API key**, or via **Remove plain-text copy now**.
- Tests: `api-key-secret.spec.ts` (bootstrap, suffixing, rotation, 60-day purge, idempotency), `plugin.spec.ts` (device A/B, rotate, clear, button purge, fresh install).

## Decisions

- No startup Notice for a missing key: fresh installs and synced-without-secret devices look identical, and a Notice would nag users who never use AI. The settings row and chat replies carry the hint instead.
- minAppVersion already 1.13.0 (>= 1.11.4 needed for SecretStorage).

## Open

- Manual runtime check needed: secret picker renders and persists the name; migration on a vault with a legacy key; second device bootstraps from synced data.json.
